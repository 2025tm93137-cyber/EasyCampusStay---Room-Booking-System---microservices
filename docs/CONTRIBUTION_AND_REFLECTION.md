# Contribution and individual reflection

Use docs/submission.json for the contribution table: each student's real name/ID, service responsibility, exact work performed and a genuine commit reference. The helper can create individual reflection worksheets under docs/reflections.

Each student supplies approximately half a page covering: actual work, the hardest problem personally solved, evidence or a test that supported the result, and what they would change next. Explain actual AI assistance and human verification. A completed reflection must be the student's own account of real work.

Service ownership is not a claim of sole authorship of generated baseline code. Review, debugging, substantive tests and clear evidence-based documentation are legitimate work when described accurately.
